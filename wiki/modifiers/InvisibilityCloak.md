# Invisibility Cloak

<p align="center"><b>Type:</b> Universal Modifier</p>

> Throw on your cloak to turn invisible for a short while.

The Invisibility Cloak can be assigned to any role. Its holder gets a **Cloak** button (bottom-left
modifier slot): using it turns them completely invisible — hidden from players, cameras, and the
admin table — for a short duration. Only the wearer (and the informed dead) see a faint outline;
even impostors see nothing. A meeting ends the invisibility early.

Like all universal modifiers, it's only assigned when its **Amount** option is above `0` (it ships
off by default) and requires TOU-Mira's non-vanilla role assignment.

## Ability

| Ability | Effect |
|---|---|
| **Cloak** | Become invisible for a short duration. |

## Options

- **Invisibility Cloak Amount** — default `0`
- **Invisibility Cloak Chance** — default `50%`
- **Cloak Cooldown** — default `25` seconds
- **Cloak Duration** — default `6` seconds
